Kindle

Amazon’s Send to Kindle accepts EPUB. On a computer, open Send to Kindle, sign in, and drop clay-jar-translation.epub onto the page. On a phone, use the Send to Kindle app or share the file to it. The book then appears in your Kindle library. You do not buy it. It is the CC BY 4.0 file.

Apple Books

On a Mac, open the EPUB and it offers Apple Books. On an iPhone or iPad, download the EPUB in Safari, tap the file, and choose Books, or use the Files app and share it to Books. The book is stored on that device.

Other reading apps

The JSON file is one object per book, chapter, and verse. The shape is described in SCHEMA.md. The plain-text file is for search and print scripts. The USFM zip is one file per book for translation tools that read USFM.
